# Fungal Mycelium Growth — NetLogo

An adaptation of an existing agent-based model exploring how branching and nutrient availability influence fungal growth.

## My Adaptations

- Modified agent replication and nutrient absorption.
- Added nutrient depletion as agents move across patches.
- Adjusted nutrient thresholds to regulate growth.

## Comparison

Both versions were run for **1,000 ticks** with identical initial agent counts and nutrient distributions. The illustrated adapted model produced a sparser, more localized network.

## How to Run

1. Open the model in NetLogo.
2. Adjust `num-hyphae`, `wiggle-angle`, and `branch-time`.
3. Click **setup**, then **grow**.
