# Traffic Basic — NetLogo Simulation

An agent-based model showing how traffic jams emerge from individual driving decisions on a continuous highway.

## How It Works

Cars accelerate when the road ahead is clear and slow down near other cars, creating stop-and-go traffic and backward-moving congestion waves.

## How to Run

1. Open **Traffic Basic** in NetLogo’s Models Library.
2. Adjust `NUMBER-OF-CARS`, `ACCELERATION`, and `DECELERATION`.
3. Click **SETUP**, then **GO**.

## Outputs

Tracks the fastest vehicle, slowest vehicle, and red car’s speed.
