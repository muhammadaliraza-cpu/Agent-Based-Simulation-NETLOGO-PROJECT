## 📌 Project Overview

This project presents an agent-based simulation of a mass attack scenario in a campus-like environment using NetLogo 6.4.0. The model explores how different attack scenarios, individual behavioral responses, and law enforcement intervention delays influence emergency outcomes.

The simulation compares scenarios involving knife and firearm attacks, focusing on how students' fight-or-flee decisions and the timing of law enforcement responses affect simulated casualties.

The project aims to provide a computational framework for exploring emergency response dynamics and understanding how individual-level decisions can influence system-level outcomes during critical incidents.

The model is intended for **academic research, educational exploration, and simulation-based scenario analysis**, rather than operational threat prediction.

## 🎯 Research Objectives

The primary objectives of this simulation are to:

1. Explore differences in simulated casualty outcomes across attack scenarios.
2. Examine how individual fight-or-flee responses influence emergency outcomes.
3. Investigate the relationship between law enforcement response delays and casualty numbers.
4. Study how interactions among individual agents generate collective emergency response patterns.
5. Provide a foundation for further research into agent-based emergency management and behavioral simulation.

## 👥 Simulation Agents

| Agent | Role in the Simulation |
|---|---|
| 🧑‍🎓 Students | Represent individuals who respond to an emergency through fight-or-flee decisions. |
| ⚠️ Attacker | Represents the source of danger in the simulated environment, with the scenario varying by attack type. |
| 👮 Law Enforcement | Represents emergency intervention, with response delay considered in scenario comparisons. |

## 🚀 How to Run the Simulation

1. Download and install [NetLogo](https://ccl.northwestern.edu/netlogo/).
2. Download the `.nlogo` model file from this repository or from NetLogo Modeling Commons.
3. Open the model using NetLogo 6.4.0.
4. Review the available controls and scenario parameters in the Interface tab.
5. Click `setup` to initialize the simulation.
6. Click `go` to run the model.
7. Observe and compare the simulation outcomes across different scenarios.

## 📊 Model Limitations

This is an exploratory computational model based on simplified assumptions about individual behavior and emergency response.

The outcomes should not be interpreted as validated predictions of real-world attacks or casualty numbers. Reliable operational applications would require empirical calibration, validation, and a more detailed representation of real-world conditions.
